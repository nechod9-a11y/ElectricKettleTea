# Electric Kettle & Tea (Forge 1.20.1)

A small Forge mod project featuring a modern, fuel-powered kettle.

## Gameplay
1. Place the Electric Kettle.
2. Right-click it with a Water Bucket.
3. Add Coal or Charcoal to start heating (about 5 seconds / 100 ticks).
4. Add a Black Tea Bag or Green Tea Bag after the water boils.
5. Right-click with an Empty Cup to collect the matching tea.
6. Right-click with an empty hand or another item to read the kettle's status.

## Build
- Minecraft 1.20.1
- Forge 47.2.0
- Java 17
- Gradle / ForgeGradle 6

Run `gradle build` from this folder after installing Gradle, or import the folder into IntelliJ IDEA and run the Gradle `build` task. The resulting mod jar will be in `build/libs/`.

This source package does not include a prebuilt JAR. Textures are simple starter placeholders and can be replaced with polished pixel-art textures.
